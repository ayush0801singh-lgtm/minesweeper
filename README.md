#  Minesweeper (Python)

A classic Minesweeper game built in Python using Tkinter, featuring
DFS-based recursive cell reveal and clean object-oriented design.

## Features
- Tkinter-based GUI
- Randomized mine placement
- Recursive DFS reveal for empty cells
- Right-click flagging
- Game-over detection

## Tech Stack
- Python
- Tkinter

## Algorithms & Concepts
- Depth First Search (DFS)
- 2D grid traversal
- Object-Oriented Programming
